Trik utama agar banner peringatan Google Apps Script (GAS) tidak terlihat saat di-host di GitHub Pages adalah dengan menggunakan properti CSS top: -36px; pada iframe, dibarengi dengan overflow: hidden; pada kontainernya. Tinggi iframe juga ditambahkan calc(100% + 36px) agar bagian bawah aplikasi tidak ikut terpotong. Langkah selanjutnya untuk GitHub Pages: Unduh file index.html di atas. Buka repositori GitHub yang ingin digunakan. Upload file index.html tersebut langsung ke root directory (halaman utama repositori). Pastikan fitur GitHub Pages sudah aktif di pengaturan repositori (arah ke tab Settings -> Pages -> pilih branch main dan folder /root -> klik Save). Jika kebetulan banner warning-nya masih sedikit "mengintip" atau justru memotong header warna navy blue Si-PANDU terlalu banyak, Anda cukup mengganti angka -36px di dalam file index.html tersebut (misalnya menjadi -40px atau -30px) sampai posisinya benar-benar pas.
